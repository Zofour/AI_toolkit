## 1.5 桌面看屏 / 操控（`C:\chatbox_temp\ai_toolkit\win_gui.py`）：操控任意 Windows GUI（微信、浏览器、游戏菜单…），**截屏 → 我看图定位 → 注入点击/键盘**
```
python ai_toolkit\cam_shot.py [out.jpg] [--index N]   # 本机摄像头拍照：自动跳过黑帧、挑最清晰帧（见 §1.6）

python ai_toolkit\win_gui.py shot --mark 1619,1217 -o m.png    # 截图前在目标点画红十字(校准，可多次)
python ai_toolkit\win_gui.py focus --title 微信                # 恢复+抢前台（ALT 技巧绕 Windows 前台锁）
python ai_toolkit\win_gui.py click X Y [--double] [--button right]   # X Y = 屏幕物理像素
python ai_toolkit\win_gui.py drag X1 Y1 X2 Y2                  # 拖拽(滑块/框选)
python ai_toolkit\win_gui.py key ctrl+v | enter | hello        # 热键 / 直接敲文字（Unicode 注入)
```
**坑（实测）：** ① `view_image` **会缩放**大图 → 照预览图标的坐标要乘 `真实宽/预览宽` 才对，动手前先用 `--mark` 把点画在截图上确认；② 坐标一律**屏幕物理像素**（脚本已 DPI 感知），全屏图内坐标==屏幕坐标，窗口图内坐标+ 窗口 rect 左上角= 屏幕坐标；③ 微信 4.0（`Weixin.exe`，类名 `Qt51514QWindowIcon`）**没有可读的 UIA 控件树**，只能靠图像坐标；④ 点击/打字是**真实注入**，会占用前台窗口与鼠标（用户无法同时用电脑），也会把前台窗口抢走；⑤ 实测微信 4.0 对 `SendInput` 的点击与 Unicode 键盘注入**都接受**（已验证：点开会话、在输入框打 test123 再 backspace 清空）；⑥ 合规：微信官方禁止自动化操控，批量发消息/加好友有**封号风险**，只做用户明确要求的单次操作。

**2026-11-23 修过的坑（很隐蔽，别再踩）**
1. **语谱图必须转置**：compute_stft 返回的是 `(列=时间, 频点)`，而 `imshow` 第一维是行(Y)。不转置时时间竖着跑、沉默段会显示成“水平黑带”（用户报的“黑框”一半是这个）。
2. **双击不要用 `ev.dblclick`**：它由系统合成事件驱动，拖拽的第一次按下也可能被当成双击 → 一拖就跳回全览。改成自己记时间/坐标（400ms 内且位移 <8px）才判双击。

### 24.2 频谱增强开关（2026-11-23 加）
第二行工具栏：「重分配」+「HPSS(原始/只留谐波/只留打击)」属**重算类**；「去斑/谱白化/CLAHE/gamma/对比线」属**显示类**（只重绘，不重算）。
- 重分配：用 h / t·h / h' 三窗估计时频重心后累积（`_reassigned_power`），谐波脊变细、瞬态变集中；实测 8s 窗口 0.4~0.6s。**代价**：图中噪声区会变“散斑”，配「去斑」一起看。
- HPSS：`median_filter(P,size=(31,1))` 估谐波、`(1,31)` 估打击，平方软掩模。
- 显示类：`display_intensity()` = 3×3 中值去斑 → 每频点减时间均值背景（`uniform_filter1d`，比中值快 10 倍）→ 归一化到 0~1 → CLAHE(16×16, clip 1.0) → gamma。
- 对比线：左原图/右增强，白色虚线可拖（按下时距线 <1.2% 视宽即判为拖分隔线）。
- **三个坑**：① 重分配里 Hz→bin 必须 `f*nfft/sr`，写成 `f*sr/nfft` 会让所有点落到图外，整张图全黑（排查了一个小时）；② 弱频点相位估计不可靠（能飞到兆赫级），必须加 `mag2 > 1e-6*peak` 和 `|Δf| < 4 bin` 双重过滤，否则能量全堆到 0Hz；③ 高斯平滑 sigma 不能超过 0.4，否则锐化完全被抹平（0.8/0.6 时和普通谱图几乎看不出区别）。
