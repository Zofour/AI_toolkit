# 提示词生图工作台 · Prompt Studio

本机 ComfyUI 驱动的「提示词汇总 → 一键生图」桌面小工具。
导入 `{提示词}{提示词}…` 格式的文本，或**直接手打提示词**；左边点一条、右边点「生成」，出图数量自己定；需要固定人物形象就打开图生图喂一张主人公图片；要风格就挂 LoRA（挂过自动记住路径）。

---

## 一、怎么启动

- **双击 `run.bat`**（或桌面快捷方式「提示词生图工作台」）。
- 首次启动会自动检查 ComfyUI：没开就自动在后台拉起（约 20~60 秒），顶部显示「ComfyUI：在线」就能用。
- 如果窗口没出现，看本目录的 `app_error.log`。

## 二、功能对照

| 需求 | 位置 |
|---|---|
| 导入提示词汇总 | 左上「导入文本文档…」 |
| 自动切割提示词 | 导入即切割，左列表显示「序号 + 内容」 |
| **直接输入提示词** | 右上方「新建提示词（自由输入）」→ 在框里写 → 点「生 成」；想留存就点「加入左侧列表」 |
| 选某条提示词生图 | 左列表点一条 → 右上方提示词框可再改 → 点「生 成」（或 Ctrl+Enter） |
| 选生成数量 | 「张数」1~20，每张用不同随机种子，串行出图 |
| 批量：多条按顺序生成 | 左列表 Ctrl/Shift 多选（或点「全选」）→ 点「批量生成所选」 |
| **LoRA 挂载 / 停止挂载** | 生成参数下方的 `LoRA` 行：「LoRA 挂载…」挂载，「停止挂载」一键停用/恢复 |
| 选模型（文生图 / 图生图） | 顶部「模型」下拉，标注了 `[SD·图文]` 之类的能力 |
| 图生图（主人公形象） | 勾「启用图生图」→「选择主人公图片…」→ 调「重绘强度」 |

## 三、提示词文件格式

识别规则（`app.py` 的 `split_prompts`）：

1. **优先按花括号切**：`{提示词A}{提示词B}` —— 支持跨行、支持嵌套括号；
   括号内开头若带 `1.`、`2、` 这类序号会自动去掉。
2. **一个花括号都没有**时，退化为「一行一条」（空行与 `#` 开头行忽略）。
3. 提示词内的连续空格/换行会被压成单个空格。
4. 编码自动尝试 UTF-8 / UTF-8-BOM / GBK / BIG5，中文不会乱码。

## 四、直接输入提示词（自由输入）

提示词框有两条使用方式：

- **跟列表联动**：点左侧某条 → 框里显示它；这时改字等于改这一条（列表里也会更新），只影响这次生成。
- **自由输入**：点「新建提示词（自由输入）」会取消选中、清空框、把光标放进去，框右上角提示「自由输入中」。
  写完直接点「生 成」——**不会改动左侧列表**；想把它存进列表以后再点，就按「加入左侧列表」。
- 「清空输入」= 取消选中 + 清空框，回到自由输入状态。

> 列表为空也能生成：直接点「新建提示词」写内容就行。

## 五、批量生成（多条按顺序）

1. 左侧列表里 **按住 Ctrl 点击**（跳选）或 **Shift 点击**（连选）多条提示词；也可以点「全选」；
2. 右上角「共 N 条，已选 M 条」实时显示选中数量；
3. 点 **「批量生成所选」** —— 按**列表顺序一条一条**生成，每条出「张数」张图；
4. 生成过程中：
   - 正在生成的条目**整行高亮**并自动滚动到可见位置；
   - 进度条按「总张数」推进，状态栏显示「批量：第 2/7 条（列表第 3 条）」；
   - 模型只载入一次、主人公图片只上传一次、LoRA 只挂一次，全程不重复卸载/加载；
   - 「停止」随时可停（当前那张会被中断，已完成的不丢）。
5. 条目数 × 张数 > 10 时会弹窗确认总数后再开始。

注意：批量用的是**列表里的文本**（改过的版本优先），不是右侧框里的临时内容。

## 六、图生图（主人公形象）

- 勾选「启用图生图」后，输入的图片被当作**主人公形象**；
- 程序会自动把下面这段**系统提示词**拼到正向提示词前面（可在界面里改，也可取消勾选）：

  > The reference image is the main character (the protagonist) of this picture. Keep the same
  > character identity: identical face, facial features, hairstyle, hair color, eye color, body type
  > and signature outfit. Do not change who this person is. Only change pose, expression, camera
  > angle, background, lighting and art style as described below.

- 输入图会自动缩到长边 ≤1024 再上传，画布尺寸以输入图为准（此时「宽/高」不生效）。
- **重绘强度**：0.4~0.55 基本保留原图构图只换画风；0.6~0.7 换背景/换姿势仍认得出人；0.8+ 会明显重画人物。SD1.5 系建议 0.6~0.7。
- 只有**支持图生图**的模型才能勾选；不支持时选项自动置灰并提示「该模型不支持图生图」。

## 七、LoRA 挂载

入口：生成参数那一行的 **「LoRA 挂载…」**（旁边实时显示当前挂载状态）。

面板里能做的事：

| 操作 | 说明 |
|---|---|
| 下拉选 LoRA | 列出 ComfyUI 里所有识别到的 LoRA（`✔ 可用`）；**挂过一次的会写进 `lora_store.json`，下次即使 ComfyUI 没扫到也照样列出来**（标 `⚠ 文件未找到`） |
| 强度 | 0~2，常用 0.6~0.9；一次挂多个时按列表顺序串到模型后面 |
| 挂载 → | 加入「已挂载」列表；同名再挂等于改强度 |
| 卸下所选 / 全部卸下（停止挂载） | 单个移除 / 清空并停用 |
| 启用 LoRA | 勾上才真正加载；取消勾选 = 保留列表但**不加载** |
| 刷新清单 / 手动填路径… | 重新扫描 ComfyUI；或手填相对路径（如 `subdir\my_lora.safetensors`） |
| **改自定义名称…** | 给选中的 LoRA 起别名（如「暖心动漫」）；已挂载列表、下拉、主界面都显示别名，真实文件名仍保留在括号里；留空或填回原名 = 恢复默认 |

两个「停止挂载」入口：

- 主界面 **「停止挂载」** 按钮：一键停用（列表保留，按钮变成「恢复挂载」，随时可恢复）；
- 面板里的 **「全部卸下（停止挂载）」**：清空列表并停用。

要点：

- 挂载配置（挂了哪些、强度多少、是否启用）与**自定义名称**存在 `lora_store.json`，重开程序自动恢复，界面上一直可见，不会偷偷生效。
- 架构要匹配：**SD 系**（SD1.5/SDXL）的 LoRA 只能配 SD 系模型，走 `LoraLoader`（同时作用于 UNET + CLIP）；**Z-Image / Anima** 走 `LoraLoaderModelOnly`，只作用于 UNET。
- 实测：同种子同提示词，挂 0.9 强度后画面差异 >99% 像素，风格明显变化。

## 八、显存策略（重要）

要求是「各模型不得同时载入显存」，实现方式：

1. 全部生成任务跑在**同一个后台线程**里，天然串行，不会并发载入两个模型；
2. 每次要用的模型和上次不同时，先 `POST /free {"unload_models":true,"free_memory":true}`
   让 ComfyUI 把**所有**模型权重（含 VAE/CLIP/LoRA）踢出显存，等 2 秒再提交新任务；
3. 连续用同一模型时不会重复卸载（避免每次都重新加载权重）；
4. 顶部「卸载显存」按钮可随时手动清空显存。

换模型的代价：SD1.5 约 1~3 秒，Anima / Z-Image 约 5~15 秒（首次读盘更久）。想快就尽量**先把同一模型的提示词都生成完再换模型**。

## 十、出图与记录

- 文件名：`<模型>_<时间戳>_<自增序号>.png`（序号全局递增，不会覆盖）
- 同目录 `生成记录.jsonl` 每行一条：提示词、实际提交的完整提示词（含主人公说明）、种子、尺寸、步数、CFG、参考图、文件列表。

## 十一、常见问题

| 现象 | 处理 |
|---|---|
| 顶部一直「离线」 | 双击 `C:\chatbox_temp\ai_toolkit\comfyui_start.bat` 手动起，或点「刷新模型」 |
| 出图超时/爆显存 | 降尺寸（512~768）、降张数；先点「卸载显存」再生成 |
| 图生图人物不像 | 调低重绘强度（0.5~0.6），或用 SD1.5 系模型；系统提示词别删 |
| 挂了 LoRA 没效果 | 检查是否「启用中」；确认 LoRA 架构和模型一致（SD 的 LoRA 配 SD 模型）；强度 0.3 以下几乎看不出 |
| LoRA 报错 node error | 下拉里标 `⚠ 文件未找到` 的路径已失效，卸下它或点「刷新清单」 |
| 批量只想从第 5 条开始 | 点第 5 条后按住 Shift 点最后一条，再点「批量生成所选」 |
| 想换输出盘 | 「输出目录…」选目录，配置存在 `config.json` |
| 报错想知道细节 | 看 `app_error.log`，或命令行 `python app.py` 看 traceback |
