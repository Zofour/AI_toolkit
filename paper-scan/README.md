# 文档扫描（安卓 App）

把手机里拍的纸（作业、讲义、票据、合同…）自动裁出来、拉正、去阴影、纸面变白，
像扫描仪扫出来的一样，然后打包成 **PDF** 或 **ZIP（JPG）**，一键分享到微信。

已在华为 ALN-00（Android 12）真机实测：裁纸 / 白化 / PDF / ZIP / 微信分享 全部通过。

---

## 一、怎么用

1. 打开 **文档扫描**（桌面图标是自己画的白纸+扫描带图标）。
2. 点底部 **「＋ 添加照片」** → 选相册里的照片（**可多选**）；
   也可以把相册里的图片直接「分享」到本应用（支持 SEND / SEND_MULTIPLE）。
   点右上 **「拍照」** 可当场拍一张再扫描。
3. 每张图会自动处理，缩略图左下角标注：
   - **已裁纸** ＝ 自动找到纸张并拉正；
   - **整图** ＝ 没找到可靠的纸边，按整张图增强（如果识别错了，点开大图用「整图重做」）。
4. 点底部 **「导出 N 张」** → 选
   - **导出为 PDF（多页文档）**：每张一页，页面按图片比例，A4 长边 842pt；
   - **导出为 ZIP 压缩包**：`扫描_001.jpg`、`扫描_002.jpg`……
5. 导出成功后弹窗里可以：
   - **分享到微信**（直达微信「发送给朋友」选聊天界面）
   - **其他应用分享**（系统分享面板：QQ / 邮件 / 网盘…）
   - **保存到手机「下载」目录**（`下载/文档扫描/`）
   - **打开预览**（看看成品）

> 小提示：缩略图右上角「×」删除；点缩略图看大图，里面有：
> **手动框选**（拖四个角自己定纸边，自动识别不准时用这个）· **整图重做**（不裁只增强）· 关闭。
> 导出的文件放在应用缓存里，重开 App 会清掉，想长期留着就点「保存到手机下载目录」。

## 二、处理流程（`PaperScanCore.java` + `DocDetect.java`，纯 Java 无依赖）

先把图缩到 520px 小图算梯度/掩膜，再在三路候选里挑最优，最后在原分辨率上做透视 + 增强。

| 步骤 | 做法 |
|---|---|
| 白纸度掩膜 | 局部亮度归一化（抗阴影）× 全局亮度 ½ 次幂（防暗背景误判）× (1−0.85×饱和度)（压木色桌面）→ Otsu → 闭/开运算 → 最大连通域 |
| 候选 A：掩膜凸包 | 掩膜边界点 → 凸包 → 枚举面积最大的 4 点组合 |
| 候选 B：每边一条直线 | Hough 取强直线，**每条边只挑一条**：要求该线两侧“纸占比”差异最大（文档扫描的常规做法，最稳） |
| 候选 C：Hough 组合 | 两对近似平行线求交（兜底：纸不在正中 / 画面里有多张纸） |
| 打分（关键） | 沿四条边逐点检查：**每条边是否压在“纸/非纸”掩膜分界上**、紧贴内侧是否大体是纸（≥45%，容忍阴影/冷暖光）、台阶支持度、四条边各自的强度（防“有一边根本没边”的假四边形）、面积、长宽比 0.35~2.8 |
| 两轮判定 | 先跑严格判据；如果全军覆没（纸几乎占满画面、边在阴影里）再用宽松判据兜底，仍不达标就落回「整图」 |
| 二次微调 | 先粗略拉正 → 在拉正后的图上**再检测一次**（此时边必然横平竖直），只接受面积 0.80~0.996 的“小幅内收” |
| 贴边吸附 | 拉正后在最外圈 5% 内找梯度最强的水平/垂直线，把四条边吸附上去（去掉顶上的本子边/桌面条） |
| 白边微裁 | 增强后纸面接近纯白，最外圈 3% 内若某行列亮度/饱和度明显不像纸就切掉 |
| 手动框选 | 识别不准时，点缩略图 →「手动框选」，拖四个角（**带 3× 放大镜 + 十字准星**，默认在左上角，手指进入左上区域会自动翻到右上角以免挡住）→ 「确定裁切」，走同一套矫正+增强 |
| 去阴影 / 白平衡 | 1/12 降采样 + 闭运算（抹掉字迹）估纸面亮度 → **单通道亮度背景**除法归一化（逐通道相除会产生彩色伪影！）→ 最亮 18% 格子全局白平衡 |
| 白化 / 锐化 | 色阶曲线（中间调不动、>0.88 压纯白，保住浅灰细线）→ 亮部向中性白靠拢 → 反锐化 0.55 → 白点归一（p92→255） |

> 任何一路候选都过不了打分（人像照、风景、屏幕照）就**不裁**，只做整图增强——宁可不裁，也不乱裁。
> 关键参数：`DocDetect.ACCEPT_SCORE`（默认 0.55）、`score()` 里的门槛值、`DET_W`（检测分辨率）。

### 实测（2026-11-22，华为 ALN-00 / Android 12）
- 6 张真实手写作业照（木色桌面、阴影、纸张轻微旋转/透视）：自动精确贴边 5 张；1 张纸顶边贴着白墙（几乎没对比度）落回「整图」，用手动框选 3 秒搞定
- 3 张非文档照（课本内页、投影屏、教室）：不裁，只增强
- 4 张合成样张（正视/强透视+阴影+暖偏/杂背景/低照度）：四角误差几像素
- 拍照保存：系统相机写入本应用给的地址后正常回到列表（曾因 provider 不允许写不存在的文件而卡死，已修）
- 耗时：3072×4096 原图在手机上约 1~1.5 秒/张

## 四、已知限制

- 纸与背景同样白、**没有明显分界**（白纸压在白桌上），或纸上有大片深阴影把边“吃”掉时，检测会失败 → 落到「整图」只增强，不乱裁；可在预览里用「整图重做」手动处理。
- 照片分辨率过低（纸上的细表格线只有 1px）时，细线会被重采样冲淡成虚线——这是采样极限，真实照片一般不会这么细。
- 微信分身（双开）装在手机上时，点「分享到微信」华为会先弹一次「用哪个微信」，选一次即可。
- 「拍照」依赖系统相机把照片写进本应用给的地址（华为相机实测会进 `ThirdCamera` 模式正常写回）；
  若某些机型不写，会提示「相机没有保存成功，请改用添加照片」。
- 处理耗时（1600×1200 测试图）：检测 ~60ms + 矫正/增强 ~100ms（手机与电脑同量级）；2400px 原图约 0.5~1s/张。

## 五、目录结构

```
paper-scan\
  android\                        安卓工程（纯框架 Java，零第三方依赖，APK ≈0.1MB）
    app\src\main\java\com\chatbox\paperscan\
      PaperScanCore.java          透视矫正 + 去阴影/白平衡/白化/锐化/贴边吸附（可在 PC 上单独跑）
      DocDetect.java              纸张四边形检测：三路候选 + 逐边打分（纯几何，无 Android 依赖）
      MainActivity.java           界面：选图/网格/预览/导出/结果弹窗
      ExportUtil.java             PDF（PdfDocument）、ZIP、微信/系统分享、存下载目录
      SimpleFileProvider.java     极简 FileProvider（不用 AndroidX，供微信读文件）
    app\src\main\res\             布局、圆角 drawable、图标
  dev\                            电脑端工具：造测试图、跑核心、按文字点击的小脚本
  build_apk.bat                   一键重建
  README.md
```
